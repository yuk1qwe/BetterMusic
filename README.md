# WeberinTV

Интерактивный браузерный прототип будущего лаунчера для Android TV. Android-приложение пока не разрабатывается.

## Запуск

В каталоге проекта выполните `python3 -m http.server 8000 --directory prototype` и откройте http://localhost:8000. Установка зависимостей не требуется. Предпросмотр: [снимок экрана](prototype/screenshot.png).

Стрелки перемещают фокус, Enter выбирает элемент, Escape возвращает на главный экран. Также поддерживается мышь. Настройки хранятся в localStorage браузера. Плитки приложений и оптимизация демонстрационные; они не запускают приложения и не изменяют телевизор.

Доступны боковая, верхняя и компактная навигация, категории, оформление, размеры плиток, анимация, профили, часы и сброс. Профили в прототипе управляют продолжительностью анимации; это не измерение производительности. Импорт, экспорт, перестановка приложений и виджеты пока не реализованы.

Исследование и предварительные архитектурные решения: [research/README.md](research/README.md).
