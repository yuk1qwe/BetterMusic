# Feather — браузер для Windows

Экспериментальная первая версия браузера на Rust и готовом CEF для Windows 10/11 x64. Проект не является Google Chrome. Перед использованием ознакомьтесь с [ограничениями](LIMITATIONS.md). Сборка не проверялась независимым аудитом безопасности.

## Установка

1. Откройте вкладку **Actions** в репозитории и выберите последний успешный запуск «Feather — Windows x64» в ветке `sever-browser`.
2. Скачайте артефакт `Feather-Windows-x64` и один раз распакуйте архив в отдельную папку.
3. Запустите `feather.exe` из распакованной папки. Не перемещайте exe отдельно от соседних DLL и папки `locales`. Windows может показать предупреждение, поскольку сборка не подписана.

Данные профиля находятся в `%LOCALAPPDATA%\SeverBrowser`: прежний путь сохранён, чтобы закладки и сессия не пропали при переименовании. Данные сайтов (включая cookies) и собственные закладки, история и адреса вкладок сохраняются локально. Для резервного копирования сначала полностью закройте браузер, затем скопируйте папку профиля. Удаление папки удалит данные. Не публикуйте профиль: он может содержать секреты и историю.

## Пользование

Кнопки `+`, `×`, `←`, `→`, `↻` управляют вкладками и навигацией. Введите адрес либо поисковый запрос и нажмите Enter или «Перейти». Поиск направляется в Google. В Lite видна только основная панель. Кнопка «Lite / Hard» открывает дополнительную панель, где можно сохранить/удалить текущую закладку, показать недавние закладки или историю и открыть текущую страницу системным браузером. Записи показываются по четыре; используйте кнопки перехода между страницами списка. Всплывающие окна открываются в отдельном окне CEF. Для скачивания показывается системный диалог сохранения.

Сочетания: Ctrl+T — новая вкладка, Ctrl+W — закрыть текущую, Ctrl+L — адресная строка, Ctrl+R — обновить, Alt+←/→ — назад/вперёд. При повторном запуске восстанавливаются до 15 адресов вкладок, а не содержимое форм. Автоматического закрытия или выгрузки вкладок нет; пользователю следует закрывать ненужные вкладки вручную. Вкладки продолжают выполнять сайты в фоне, даже в Lite.

## Сборка и проверка

В Windows установите Visual Studio C++ Build Tools, CMake, Ninja и Rust 1.99.1. В каталоге проекта выполните:

```powershell
cargo run --locked --release --bin bundle
$env:PATH = "$PWD\target\release;$PWD\target\debug;$env:PATH"
cargo test --locked --release --lib
```

Результат — `dist\Feather\feather.exe` и его файлы. При первом запуске компиляции cef-rs получает готовую бинарную сборку CEF из каталога Spotify/CEF с проверкой SHA-1 по опубликованному индексу, компилирует небольшой CEF DLL wrapper; Chromium и CEF из исходников не компилируются. Windows bootstrap создаёт процессы с песочницей. Не заменяйте его на обычный exe и не включайте `--no-sandbox`. Полная проверка CI дополнительно запускает локальный HTTP-сервер, открывает окно, создаёт вкладку, переходит на страницу и проверяет отсутствие `--no-sandbox` в командной строке renderer; это не доказывает полноценность песочницы.

## Обновление движка

Закреплены `cef = 156.4.0+156.0.26`, CEF 156.0.26 / Chromium 156.0.8078.88, Rust 1.99.1 и зависимости в `Cargo.lock`. Сверяйте [выпуски cef-rs](https://github.com/tauri-apps/cef-rs/releases), [официальный каталог сборок CEF](https://cef-builds.spotifycdn.com/index.html) и [уведомления Chromium](https://chromereleases.googleblog.com/). При обновлении измените точную версию cef в Cargo.toml, выполните `cargo update -p cef` и `cargo update -p cef-dll-sys`, проверьте API, соберите и повторите все тесты на Windows. Бинарники CEF и Rust-привязки должны соответствовать друг другу. На Windows для сравнения версий выполните `./check-cef.ps1` в установленной папке (или `./scripts/check-cef.ps1` в исходниках). Автоматической доставки обновлений пользователю пока нет: нужно скачать новый ZIP, сохранив профиль отдельно. Не используйте устаревшую версию для важных аккаунтов.

Потребление памяти специально не оценено; никаких утверждений об экономии нет. Для измерения сравните в диспетчере задач суммарную память всех процессов `feather.exe` на одном и том же наборе вкладок, после одинакового времени загрузки, в обоих режимах; отдельно проверьте воспроизведение аудио и несохранённые формы.

Исходный код проекта распространяется под MIT; CEF и сторонние компоненты имеют собственные лицензии и перечислены в `CREDITS.html` поставки.
