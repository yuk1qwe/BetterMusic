# Security review and network destinations

This is a partial source review, not a guarantee that the application or its dependencies are free from malware. The imported source is WinYandex commit c532409cab0e3232ebd48010fa4d36d5489074f7. The repository does not contain checked-in exe or dll files. The Windows workflow restores NuGet packages and runs their build tools; dependencies and GitHub Actions have not undergone an independent complete audit. Direct NuGet package versions are pinned; transitive packages do not yet use a lock file.

The account authorization URL uses oauth.yandex.ru; account info uses login.yandex.ru and music API requests use api.music.yandex.net. These are Yandex domains. This source review does not independently certify each API operation or OAuth client, nor does it verify account behavior. OAuth is sent on requests explicitly addressed to the music API or login endpoint. Download URLs returned by the service use a separate HTTP client without the OAuth header and require HTTPS at the initial URL; the resulting media functionality needs an account test. The existing embedded browser login and redirect validation still need a dedicated security review.

Other destinations exist: LRCLIB and Genius receive song metadata for lyric lookup only when the user enables external lyrics; GitHub supplies optional update and FckCensor data; Slopless and Supabase provide optional track features; Spotify is used for import; Discord for rich presence; Google Fonts for the optional OBS widget. These are not Yandex APIs. Discord, FckCensor, Slopless and the local OBS server default to off for new settings, but existing settings can enable them. Additional dynamic media and artwork URLs are supplied by remote responses. This is not an exhaustive traffic capture.

No new token is saved to session.json or .env. Legacy plaintext files are not migrated or erased automatically. Old tokens may need revocation. The previous automatic clipboard polling and execution of downloaded installers have been disabled. The CI workflow runs the Defender command-line custom scan on the published directory and checks its exit code; consult the specific run logs for the actual result. Cache cleanup is limited to indexed audio files inside the cache audio directory; invalid index paths are discarded. FckCensor network initialization and replacements are disabled when its setting is off. A clean antivirus scan cannot prove the absence of malicious code.

Follow-up hardening: the optional OBS server no longer grants wildcard browser CORS access and limits concurrent event streams to eight. It still has no authentication; local processes can read playback metadata while the server is enabled. Optional remote audio replacements are restricted to HTTPS on raw.githubusercontent.com under the upstream FckCensorData repository; future upstream changes to its hosting may require an explicit update. Update downloads require the expected GitHub release URL, a safe filename, and a size limit; downloaded updates are never executed automatically. Direct Windows SDK package references are pinned; transitive packages are not yet locked, so builds are not fully reproducible.
